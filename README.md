# Zenodo reproducibility package

This repository contains the data and R scripts used to reproduce the computational analyses associated with the study of wild-grapevine endophytes and their effects against *Botrytis cinerea*.

## Directory structure

- `data/`: machine-readable input datasets used by the analysis scripts.
- `scripts/`: one R script per biological assay.
- `output/`: not included in the distributed archive. Each script creates its corresponding output subfolder automatically when executed.

## Running the analyses

Run each script from either the repository root or the `scripts/` directory. The scripts detect the project directory automatically and create the required output folders under `output/`.

The generated subfolders are:

- `output/01_indole_production/`
- `output/02_mineral_solubilization/`
- `output/03_in_vitro_antagonism/`
- `output/04_growth_kinetics/`
- `output/05_acc_utilization/`
- `output/06_peg6000_osmotic_stress/`
- `output/07_disease_severity/`
- `output/08_culturable_bacterial_populations/`
- `output/09_qpcr_analysis/`

Generated outputs include manuscript figures, supplementary tables and statistical results as applicable to each assay.

## CFU analysis

Inferential analyses use within-plant baseline-normalized changes:

`Delta log10 CFU = log10 CFU(t) - log10 CFU(T0)`

T0 is used for baseline normalization. Mixed-effects models are fitted to T1-T4 separately for leaf and soil:

`Delta_log10_CFU ~ Treatment * Time + (1 | PlantID)`

Treatment comparisons within each post-baseline sampling time are based on estimated marginal means with Tukey adjustment.
